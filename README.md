# CourseHub — лабораторная 7

Задания 1–9 по файловому вводу-выводу. `Main` запускает каждое задание отдельным вызовом.

Автор: Горбачев Д.В.

Отчёт: [PDF](output/pdf/Горбачев_ДВ_Отчет_практическая_работа_7.pdf) · [DOCX](output/docx/Горбачев_ДВ_Отчет_практическая_работа_7.docx)

## Запуск

Нужны JDK 21+ и Gradle.

```sh
gradle run
```

## Реализация

| № | Файл | Что проверять |
|---|---|---|
| 1 | `demo/Task01FilesReadWrite` | UTF-8, отсутствующий файл, путь-каталог |
| 2 | `demo/Task02BufferedReaderWriter` | Буферное чтение, подсчёт строк и символов, bytes → chars |
| 3 | `demo/Task03TryWithResources` | Исключение в pipeline и обратный порядок закрытия ресурсов |
| 4 | `demo/Task04FilesLines` | Владение ленивым `Files.lines` и закрытый возвращённый stream |
| 5 | `demo/Task05BinaryFormat` | Magic, версия, записи, неизвестная версия, обрезанный файл |
| 6 | `demo/Task06AtomicMove` | Временный файл в целевом каталоге, закрытие до move, fallback без atomic move |
| 7 | `demo/Task07AtomicImport` | All-or-nothing, ошибки с номерами строк, тип `CatalogImportResult` |
| 8 | `demo/Task08StreamingImport` | Чтение по строкам, счётчики, лимит ошибок, отмена и публикация через временный файл |
| 9 | `demo/Task09VersionedFormat` | Версии 1 и 2, миграция, SHA-256, отказ от будущей версии и повреждённых данных |

Текстовая запись каталога: `id;title;durationHours;completedHours`. Для версии 1 поле пройденных часов отсутствует и после миграции равно нулю.

Потоковый импорт держит в памяти текущую строку и ограниченное число ошибок; корректные записи сразу идут во временный файл. При отмене временный файл удаляется, целевой каталог остаётся прежним.
